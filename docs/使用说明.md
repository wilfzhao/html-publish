# 有巢（Youchao）使用说明

有巢（Youchao）是一个 HTML 原型发布工具。

你可以用它上传原型、在线预览、分享链接，以及管理不同版本。

## 一、创建项目

1. 打开有巢，进入 **Dashboard**。
2. 点击右上角 **New Project**。
3. 填写项目信息：
   - **Project Name**：项目名称，必填。
   - **Description**：项目说明，选填。
   - **Custom URL**：自定义访问地址，选填。
   - **Visibility**：选择公开访问或密码保护。
4. 点击继续，进入上传页面。

如果选择密码保护，需要设置至少 4 位密码。访问者打开原型时需要输入密码。

## 二、上传原型

### 方式一：在网页中上传

1. 将 `.html` 文件拖入上传区域，或点击选择文件。
2. 填写本次版本说明，例如“首页改版”或“评审版本”。
3. 如有需要，可以填写版本号，例如 `v1.0`。
4. 点击 **Upload & Deploy**。

上传完成后，新版本会自动成为当前版本。

> 网页端适合上传单个 HTML 文件。如果原型包含独立的图片、CSS 或 JavaScript 文件，请联系开发同事协助发布。

### 方式二：通过 Codex 技能发布

如果原型由 Codex 创建或修改，也可以让 Codex 直接发布：

1. 打开目标项目的 **Settings → AI Publish**。
2. 按页面提示安装发布技能。首次使用时需要完成一次浏览器授权。
3. 在 Codex 中发送：

```text
使用 publish-html-prototype 技能，把当前原型发布到「项目名称」，备注「本次修改说明」
```

Codex 会自动检查原型并完成发布。发布成功后，会返回当前版本链接和本次版本的专属链接。

这种方式适合包含图片、样式或交互脚本的完整原型，不需要手动整理上传文件。

## 三、预览和分享

进入项目后，默认打开 **Preview** 页面。

你可以：

- 切换电脑、平板和手机尺寸查看效果。
- 点击 **Open**，在新窗口中打开原型。
- 点击复制按钮，将当前原型链接发送给其他人。

分享当前版本时，建议复制 **Preview** 页面中的项目链接。以后发布新版本后，这个链接会自动展示最新内容。

## 四、发布新版本

1. 打开目标项目。
2. 切换到 **Versions**。
3. 点击 **New Version**。
4. 上传新的 HTML 文件并填写版本说明。
5. 点击 **Upload & Deploy**。

每次上传都会保留为一个独立版本，不会覆盖之前的版本。

## 五、查看和管理历史版本

在 **Versions** 页面中，可以查看项目的所有历史版本。

- 点击眼睛图标：预览该版本。
- 点击复制图标：复制该版本的专属链接。
- 点击回滚图标：将该版本重新设为当前版本。
- 点击删除图标：删除不再需要的历史版本。

当前正在使用的版本会显示 **CURRENT** 标记。

> 当前版本不能直接删除。如需删除，请先回滚到其他版本。

## 六、修改项目设置

进入项目的 **Settings** 页面，可以修改：

- 项目名称
- 项目说明
- 项目图标
- 自定义访问地址
- 公开或密码保护
- 项目密码

页面底部可以删除整个项目。删除后，项目及其所有历史版本都会被移除，请谨慎操作。

## 七、常见问题

### 上传后图片或样式丢失

网页端只会上传一个 HTML 文件。如果页面还引用了其他文件，请联系开发同事协助发布完整原型。

### 分享后看到的不是最新版本

打开 **Versions**，确认需要展示的版本带有 **CURRENT** 标记。也可以点击该版本的回滚按钮，将它设为当前版本。

### 忘记项目密码

请联系项目创建者或平台管理员处理。

### 无法删除某个版本

当前版本不能直接删除。请先将其他版本设为当前版本，再执行删除。
